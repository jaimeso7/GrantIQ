GrantIQ

Recurring grant discovery, explainable matching, and a staff-managed application pipeline.

Discover grants · My pipeline · Team research · Data sources

How the application works

  1. Organization profile and search keywords define the discovery context.
  2. The scheduler starts source retrieval and normalization.
  3. Eligibility checks and local semantic matching produce an explainable assessment.
  4. SQLite preserves grants, evidence, staff decisions, and pipeline stages.
  5. Server-rendered browser pages let the team review, organize, and export results.

Stack: Python, FastAPI/Uvicorn, SQLAlchemy/SQLite, Jinja2, CSS/JavaScript, and Sentence Transformers/MiniLM.

Private research stays local

The public repository contains starter configuration. Internal source documents, funder details, and meeting handouts are excluded. Follow the README to configure your own organization. This overview is shown when no local sprint-review presentation is installed.
